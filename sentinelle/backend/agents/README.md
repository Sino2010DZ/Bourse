# Agents

Un sous-dossier par section (ex. `agents/bourse/`), un fichier `.md` par agent :

```
---
nom: Trader
section: bourse
role: Suit les cours de mes actions et signale les gros mouvements.
outils: [bourse_cours, base_de_donnees]
systeme: tous        # ou mac / windows
---
Instructions détaillées de l'agent…
```
