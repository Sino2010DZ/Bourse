# 0. Faire tourner le site sur votre ordinateur

« En local » veut dire : le site tourne sur **votre** ordinateur, sans Internet pour l’hébergement.
Pratique pour essayer et modifier avant de mettre en ligne.

## Étape 1 — Installer Node.js (une seule fois)

1. Allez sur **https://nodejs.org**.
2. Téléchargez la version **LTS** (le gros bouton vert) et installez-la comme n’importe quel programme
   (Suivant, Suivant, Terminer).

## Étape 2 — Télécharger le projet

1. Allez sur **https://github.com/Sino2010DZ/Bourse**.
2. Cliquez le bouton vert **Code** → **Download ZIP**.
3. Ouvrez le fichier ZIP téléchargé → **Extraire tout** (Windows) ou double-clic (Mac).
   Placez le dossier où vous voulez, par exemple sur le Bureau.

## Étape 3 — Lancer

- **Windows** : double-cliquez sur **`Demarrer-Windows.bat`**.
  Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires → Exécuter quand même**.
- **Mac** : clic droit sur **`Demarrer-Mac.command`** → **Ouvrir** → **Ouvrir**
  (la première fois seulement, car le Mac se méfie des fichiers téléchargés).

La première fois, l’installation prend 1 à 3 minutes. Ensuite le site s’ouvre tout seul sur
**http://localhost:5173**. Gardez la fenêtre noire ouverte tant que vous utilisez le site.

## Bonus — Le voir sur votre iPhone

L’iPhone doit être sur le **même Wi-Fi** que l’ordinateur. Dans la fenêtre noire, une ligne
`Network: http://192.168.x.x:5173` s’affiche : tapez cette adresse dans Safari sur l’iPhone.

## Bon à savoir

- En local, tout est gratuit et ouvert, comme en ligne.
- Les prix et graphiques viennent de TradingView : il faut quand même Internet.
- Votre watchlist locale est séparée de celle du site en ligne (ce sont deux adresses différentes).
- Pour récupérer une nouvelle version : retéléchargez le ZIP (étape 2).
